## 核心理念

传统的加权打分法、AHP 等工具把你的输入当作**确定的**。但真实决策中从来不是：

- **你拿不准**每个因素到底有多重要
- **你拿不准**每个选项到底值多少分
- **你拿不准**自己有没有遗漏什么

RobustPick 模拟 **10,000+ 次**——你的权重和评分在你设定的不确定范围内随机波动。结果不是一个答案，而是一份**稳健性诊断**：

| 指标 | 说明 |
|:-----|:-----|
| 🏆 **胜率** | 每个选项在所有模拟中获胜的频率 |
| 📊 **名次范围** | 每个选项的最好/最差排名 |
| 🔄 **敏感度** | 权重稍微一偏，结论会翻盘吗？ |
| 🎯 **翻盘路径** | 要让落后选项反超，需要改变什么？ |

## 功能

### 1. 多因素加权输入
- 最多 **8 个选项** × **8 个维度**
- 每个维度设置**权重**（1-10）和**不确定度**（低/中/高）
- 每个选项在每个维度上**打分**（1-10），也有自己的不确定度
- 采用**三角分布采样**，比正态分布更适合有边界的偏态评分

### 2. 稳定性盾牌 🛡️
核心输出 —— 三级稳定性评估：

| 状态 | 含义 |
|:-----|:------|
| **稳定**（胜率 > 60%）| 领先选项在几乎所有模拟场景中占优，结论可靠 |
| **悬**（胜率 40-60%）| 结论对假设敏感——稍微调整权重结果就可能变 |
| **不确定**（胜率 < 40%）| 没有明显更优的选项，差距太小不足以建立信心 |

### 3. 翻盘路径分析
当你偏好的选项不是模拟冠军时，RobustPick 自动计算**三类翻盘路径**：

| 路径 | 回答的问题 |
|:-----|:-----------|
| **最小调整** | "哪个维度的权重只需要动最少，就能翻盘？" |
| **优势维度** | "这个选项本来有优势的维度，是不是被低估了？" |
| **盲区诊断** | "你给最低权重的维度，反而可能帮它翻盘？" |

每条路径附带 **「应用」按钮**——一键应用建议权重、重新跑模拟、看效果。

### 4. 两两对比解释器
每对选项之间，你得到的不只是数字：

- **正面交锋胜率**：A 72% vs B 28%
- **维度级拆解**："A 靠薪水和成长空间领先，但在通勤上落后"
- **中心权重偏差**（可选）：你设的权重 vs 选项真赢的时候的实际权重——揭示偏好与实际之间的落差（灵感来自 SMAA 文献）

### 5. 场景预设

| 场景 | 维度 |
|:-----|:-----|
| 💼 选工作 | 薪资、成长空间、WLB、团队氛围、通勤 |
| 🏠 选房子 | 价格、地段、面积、房龄、交通 |
| 💻 技术选型 | 性能、生态、成本、学习曲线、社区 |
| 🤝 供应商 | 价格、质量、交期、售后、技术能力 |
| 🌆 选城市 | 就业、房价、气候、教育、生活成本 |
| 🎓 选学校 | 排名、学费、就业、安全、文化适配 |

### 6. 持久化与便携
- **自动保存**到浏览器 localStorage —— 关掉再打开数据还在
- **导出/导入 JSON** —— 把完整分析分享给其他人
- **一键复制摘要** —— 结论、胜率、路径全在一个文本块里

## 工作原理

### 蒙特卡洛引擎

```
每次模拟（自适应 2,000 轮起，完整 10,000 轮）：
  1. 从每个权重的三角分布中采样一个值
  2. 从每个评分的三角分布中采样一个值
  3. 计算每个选项的加权总分
  4. 记录胜者 + 两两对比 + 排名
```

**自适应收敛**：如果连续 3 个 batch 排名稳定，提前终止（受 SIMA 方法启发）。

### 中心权重向量（SMAA）

当一个选项获胜时，模拟会记录*当时用的是什么权重值*。迭代数千次后，就能构建出该选项的**中心权重画像**：

> "A 赢的时候，薪资权重的平均值为 8.2——但你设的是 6。"

这揭示了你的**设定偏好**与**真实获胜条件**之间的隐性落差。

### 翻盘三路径算法

不是暴力搜索整个权重空间，RobustPick 用：

1. **二分搜索**每个维度找到翻盘的最小权重偏移（路径 A）
2. **评分对比**当前冠军找到自然优势（路径 B）
3. **极端值测试**低权重维度发现盲区（路径 C）

**缓存层**确保三条路径之间的 MC 计算共享结果，总计算量只相当于跑一次 2,000 轮模拟。
